# Excluded Fiction

Fiction is excluded from the main vault by default. A small exceptional-fiction category may be considered later when a work has unusual educational, philosophical, historical, scientific, or cultural value.

## Current policy

The optional fiction list will be validated separately. No fiction summary should be created in the nonfiction categories, and no fictional work should be treated as nonfiction merely because it contains useful ideas.

See [[34-Optional-Exceptional-Fiction/README|Optional Exceptional Fiction]] for the final exception policy.
