# 📚 Visual Book Summary Gallery & Library

> Interactive visual card gallery of all book summaries, categorized by Knowledge Pillar, difficulty, and reading status.

---

## 🌟 Top 5-Star Mastered Summaries

```dataview
TABLE WITHOUT ID
  file.link AS "Title",
  author AS "Author",
  pillar AS "Pillar",
  difficulty AS "Difficulty"
FROM "md"
WHERE rating = 5 OR contains(tags, "top-tier")
SORT file.name ASC
```

---

## 🏛️ All Summaries by Knowledge Pillar

```dataview
TABLE WITHOUT ID
  file.link AS "Book",
  author AS "Author",
  category AS "Category",
  status AS "Status"
FROM "md"
SORT pillar ASC, category ASC, file.name ASC
```

## 🎯 Spaced Repetition Queue

```dataview
TABLE WITHOUT ID
  file.link AS "Book Note",
  author AS "Author",
  pillar AS "Pillar"
FROM "md"
WHERE contains(tags, "spaced-repetition") OR status = "reading"
```
